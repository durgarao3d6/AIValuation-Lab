# AIValuation Lab

Public-data financial modelling and valuation scenario prototype.

Initial implementation includes a Streamlit app, deterministic valuation engine, CSV validation, fictional sample data, formula-based Excel export, unit tests and CI. See the complete project files in this repository.

**Not investment advice.** Bundled data is fictional; no automatic financial disclosure verification.

## Run

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Test

```bash
python -m pytest -q
```
